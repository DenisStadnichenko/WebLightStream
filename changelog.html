Changelog

Release history of the StadFlow Android app.

v1.0 — September 2026

Latest Version

  • Native Kick.com sign-in via OAuth with automatic stream key retrieval.
  • Twitch sign-in switched to authorization code flow with automatic token refresh.
  • Local recording: save every stream to Movies/StadFlow.
  • Automatic reconnect of every destination on connection loss.
  • Permissions are now requested only for the source you use (camera, microphone, screen).
  • Bluetooth headset audio support and camera zoom.
  • Landscape layout for all screens.
  • Free / Pro plans: 2 simultaneous destinations on Free, unlimited on Pro.
  • Ukrainian and Russian translations.
  • Stability and security fixes for YouTube broadcasts and destination management.

Beta — June 2026

  • Multi-destination streaming to YouTube, Twitch and custom RTMP / RTMPS / RTSP / SRT / UDP servers.
  • Multiple accounts per platform.
  • Camera, screen capture and video file sources.
  • Internal audio capture on Android 10+.
  • Resolution, FPS and bitrate settings.
